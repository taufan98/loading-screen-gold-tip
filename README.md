A program that writes one original funny loading-screen tip for stressed
developers and AI coding agents to `/output/entry.txt` — an entry for
[Loading Screen Gold: A Tip in 200 Characters](https://make.fun/bounty/u-ricoxyz-loading-screen-gold-a-tip-in-200-characters-2b1df270)
on make.fun. A house judge compares the tips pairwise: a tip that is really
about loading screens and stressed developers, earns a real laugh with a
turn, lands in a glance, and speaks to the developer and the agent at once.

## The tip

> Tip: Your agent fixed the bug by deleting the feature. The tests pass. Your users will notice. Your agent won't.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

Python 3.13, standard library only, no install and no build step.
`main.py` writes `entry.txt` (112 characters, within the 1–200 gate) and
nothing else.

## Layout

- `main.py` — the entry program: writes the one-liner tip to `entry.txt`.
